# Win Admin Toolkit

**Українська** · [English](README.en.md)

Набір PowerShell-інструментів для адміністратора невеликого офісу на Windows: інвентаризація, діагностика ПК і мережі, налаштування нових комп'ютерів, аудит безпеки мережі та звіти Active Directory.

- **Одне меню** для всіх інструментів — `Admin-Menu.bat`.
- **Результат — HTML-звіт** на робочому столі: пошук, сортування, експорт у CSV, світла й темна тема, друк.
- **Нічого не треба встановлювати**: працює на вбудованому PowerShell 5.1 у Windows 10/11.
- **Зрозумілою мовою**: кожна знайдена проблема — з поясненням і порадою, що робити.

## Інструменти

| Інструмент | Що робить | Права адміністратора |
|---|---|---|
| [Інвентаризація ПК](#інвентаризація-пк) | Залізо, Windows, серійні номери, мережа, встановлене ПЗ | Не потрібні |
| [Аптечка ПК](#аптечка-пк) | Чому комп'ютер гальмує чи глючить і що з цим робити | Бажано, скрипт запитає сам |
| [Налаштування нового ПК](#налаштування-нового-пк) | Тиха установка програм через winget і базові налаштування Windows | Потрібні, скрипт запитає сам |
| [Діагностика мережі](#діагностика-мережі) | Покроково знаходить, де саме зламалась мережа | Не потрібні |
| [Сканер мережі](#сканер-мережі) | Пристрої в мережі, відкриті порти, ризики і як їх закрити | Не потрібні |
| [Звіти Active Directory](#звіти-active-directory) | Неактивні облікові записи, паролі, блокування, адміни, версії ОС | Звичайний доменний користувач |

## Швидкий старт

1. Натисніть **Code → Download ZIP** і розпакуйте архів у будь-яку папку.
2. Розблокуйте файли. Windows блокує скрипти, завантажені з інтернету. Відкрийте PowerShell у розпакованій папці й виконайте:
   ```powershell
   Get-ChildItem -Recurse | Unblock-File
   ```
3. Запустіть **`Admin-Menu.bat`** і виберіть інструмент за номером.

Кожен інструмент можна запустити й окремо — через `Run-*.bat` у його папці або напряму:

```powershell
powershell -ExecutionPolicy Bypass -File .\Network-Diag\Test-Network.ps1 -Quick
```

## Інвентаризація ПК

`PC-Inventory\Get-PCInventory.ps1`

Збирає повну картку комп'ютера в один HTML-файл:

- модель, серійний номер (з BIOS або материнської плати), BIOS, домен чи робоча група, користувач;
- процесор, планки пам'яті по слотах, фізичні диски з типом (NVMe / SSD / HDD) і станом, заповненість розділів;
- відеоадаптери з версіями драйверів, мережеві адаптери з IP, MAC, шлюзом і DNS;
- встановлене ПЗ з версіями, видавцем і датою встановлення — з пошуком.

Зручно для обліку техніки та перед заміною чи ремонтом ПК.

## Аптечка ПК

`PC-Health\Test-PCHealth.ps1`

За хвилину показує, чому комп'ютер гальмує або глючить, і що з цим робити. Перевіряє:

- час без перезавантаження і оновлення, що чекають перезавантаження;
- місце на дисках, стан дисків (SMART), систему на HDD;
- хто навантажує пам'ять і процесор;
- сині екрани, раптові вимкнення, збої програм, помилки диска в журналах;
- давність оновлень Windows, антивірус, пристрої без драйверів, важливі служби;
- автозавантаження, тимчасові файли, мережу, батарею ноутбука, схему живлення.

Можна перевірити цей ПК або інший за ім'ям через WinRM (потрібні домен і права адміністратора на тому ПК):

```powershell
.\PC-Health\Test-PCHealth.ps1 -ComputerName BUH-03
```

На локальному ПК після перевірки пропонує швидкі виправлення: очистити тимчасові файли, старші за добу, і запустити зупинену службу друку.

## Налаштування нового ПК

`PC-Setup\Setup-NewPC.ps1`

Розгортання робочого місця без ручних кліків:

- перевіряє winget і, якщо його немає (часто на Windows 10), встановлює;
- показує меню програм: Chrome, AnyDesk, 7-Zip, Acrobat Reader, Notepad++, VLC, Telegram, Zoom та інші. Вже встановлені пропускає;
- програми, що ставляться лише в профіль користувача, встановлює від імені того, хто сидить за ПК, а не адміністратора;
- перед змінами створює точку відновлення;
- налаштовує часовий пояс, живлення, показ розширень файлів, Провідник, вимикає рекламу й «рекомендовані» програми, за бажанням вмикає RDP з NLA;
- налаштування Провідника застосовує і для профілю за замовчуванням — тобто для всіх майбутніх користувачів;
- перейменовує ПК і зберігає журнал у `C:\ProgramData\PC-Setup`.

Для масового розгортання без меню:

```powershell
.\PC-Setup\Setup-NewPC.ps1 -Auto -ComputerName BUH-03
```

Список програм і налаштувань змінюється на початку файлу (розділ `НАЛАШТУВАННЯ`).

## Діагностика мережі

`Network-Diag\Test-Network.ps1`

Перевіряє ланцюжок по черзі й робить висновок, де саме проблема:

**адаптер → IP-адреса (DHCP) → шлюз → інтернет → DNS → сайти (HTTP / HTTPS)**

Також:

- пінг із втратами та джитером, якість для IP-телефонії;
- трасування маршруту і тест швидкості;
- розпізнає адресу 169.254 (не відповів DHCP), сторінку авторизації гостьового Wi-Fi, неточний годинник ПК;
- проксі, файл hosts, «загальнодоступний» тип мережі;
- доступність контролера домену і ваших серверів за портами.

Швидкий режим без трасування і тесту швидкості (~20 с): параметр `-Quick`. Свої сервери для перевірки додаються в розділі `НАЛАШТУВАННЯ` на початку файлу.

## Сканер мережі

`Network-Scan\Scan-Network.ps1`

Сканер з акцентом на безпеку: що є в мережі, що відкрито і як це закрити.

- знаходить пристрої через ping, ARP, TCP та NetBIOS — зокрема ті, що блокують ping;
- визначає ім'я, MAC, виробника й тип пристрою: ПК, принтер, камера, роутер, NAS;
- перевіряє ~35 важливих портів (RDP, SMB, Telnet, VNC, бази даних, камери, MikroTik Winbox тощо) і для кожного пояснює ризик та як його закрити;
- показує, що видно з інтернету (Shodan InternetDB) і що прокинув роутер через UPnP;
- перевіряє сам цей ПК: RDP, NLA, брандмауер, SMBv1, відкриті порти;
- звіряє з Active Directory: пристрої поза доменом і ПК домену, що не відповідають;
- пам'ятає попередні сканування й показує нові та зниклі пристрої, а також вільні IP-адреси.

```powershell
.\Network-Scan\Scan-Network.ps1 -Subnet 192.168.10.0/24 -NoExternal
```

Без `-Subnet` сканує мережі всіх активних адаптерів, включно з VPN. `-NoExternal` вимикає перевірку того, що видно з інтернету.

> Скануйте лише мережі, якими керуєте або на сканування яких маєте дозвіл.

## Звіти Active Directory

`AD-Reports\Get-ADReports.ps1` · **бета**

10 звітів з меню, окремо або всі одним файлом:

1. Неактивні користувачі
2. Неактивні комп'ютери
3. Паролі, що скоро спливають
4. Заблоковані облікові записи
5. Групи та їх учасники
6. Користувачі та їх групи
7. Привілейовані групи (вкладені групи розгорнуто)
8. Паролі без терміну дії
9. Вимкнені облікові записи
10. Усі комп'ютери та версії Windows (із позначкою застарілих ОС)

Плюс політика паролів домену і меню розблокування облікових записів з підтвердженням.

```powershell
.\AD-Reports\Get-ADReports.ps1 -Report All -InactiveDays 60
```

Потрібен модуль ActiveDirectory (RSAT) — якщо його немає, скрипт запропонує встановити. Для розблокування потрібні права адміністратора або хелпдеску.

## Вимоги

- Windows 10 або 11, вбудований Windows PowerShell 5.1.
- Звіти AD: ПК у домені та RSAT.
- Віддалена перевірка в Аптечці: домен і ввімкнений WinRM на цільовому ПК.

## Де зберігаються дані

| Що | Де |
|---|---|
| HTML-звіти | Робочий стіл поточного користувача |
| Журнал налаштування нового ПК | `C:\ProgramData\PC-Setup` |
| Історія сканувань і база виробників | `C:\ProgramData\NetScan` |

Зовнішні сервіси, до яких звертаються інструменти:

- **Діагностика мережі**: `msftconnecttest.com`, `google.com`, `api.ipify.org`, `speed.cloudflare.com`.
- **Сканер мережі**: `api.ipify.org` і `internetdb.shodan.io` — перевірка, що видно з інтернету, вимикається параметром `-NoExternal`; `standards-oui.ieee.org` — база виробників мережевих карт, завантажується раз на 90 днів.

- **Налаштування нового ПК**: завантажує програми через winget з їхніх офіційних джерел.

Крім цих запитів, інструменти нічого нікуди не надсилають: звіти та історія залишаються на вашому ПК.
